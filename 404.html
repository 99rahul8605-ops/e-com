Setup notes

1. Real Google sign-in: create an OAuth Client ID in Google Cloud Console → Credentials, add your live domain as an authorized origin, then replace GOOGLE_CLIENT_ID near the top of the script with it.

2. Real payments: the "Pay Now" button currently marks orders paid instantly for demo purposes. To take real money, add a Razorpay/Stripe checkout on a backend and confirm payment before releasing the download link.

3. File delivery: replace each product's download link with a real file URL (Google Drive share link, S3, etc.) — ideally one that expires or is unique per order.

4. Hosting: this file is self-contained. Upload it as-is to any static host (Netlify, Vercel, GitHub Pages) to go live.
