Setup notes

1. Backend: deploy the backend folder to Render/Railway and connect MongoDB Atlas through environment variables.

2. Frontend: set the backend URL and Google Client ID in config.js, then publish the root files on GitHub Pages.

3. Orders: users submit UTR numbers. Update status here to Pending, Paid, Delivered or Rejected. Paid/Delivered orders automatically reveal download links inside the user's My Orders page.

4. Security: MongoDB URI, admin password and JWT secret stay only in backend environment variables. Never put them in GitHub Pages files.
